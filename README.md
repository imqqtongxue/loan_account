# 个人借款管理工具 (Loan Account Manager)

## 项目简介
这是一款基于 Python 和 Tkinter 开发的轻量级个人借款管理工具。旨在帮助用户清晰、安全地管理日常的借出与借入记录。

## 主要功能

- **记录管理**：支持快速添加借出和还款记录，支持自定义备注。
- **数据统计**：按借款人分类统计未结清的金额，账目一目了然。
- **时间排序**：清晰展示每一笔交易的时间线，方便追溯历史。
- **数据导出**：支持一键导出所有记录为 Excel 文件，方便二次分析与备份。
- **本地存储**：数据以 JSON 格式安全存储在本地，无需联网，保护隐私。
- **图形界面**：采用原生 Tkinter 构建，开箱即用，无需复杂配置。

## 如何运行

### 环境要求
- 确保你的电脑已安装 **Python 3.x** 环境。
- 本程序仅依赖 Python 内置库（`tkinter`, `json` 等），无需额外安装第三方依赖。
